# Karten-Asset

Das Kartenbild liegt als **`map.jpg`** in diesem Ordner:

    app/src/renderer/assets/map.jpg

- Aktuell: **V10.2 Gateway Map (26.09.2026)** von RaidAtlas, top-down, 3072 × 3072 px (aus der 4K-Fassung).
- Der Bildausschnitt ist identisch mit der vorherigen Karte, die Kalibrierung (Welt → Bild) bleibt gültig.
- Beim Start automatisch geladen. Fehlt das Bild, zeigt die Karte einen Platzhalter.
- `raidatlas-logo.png`: RaidAtlas-Logo für den Karten-Hinweis unten rechts (klickbar, öffnet raidatlas.app).
